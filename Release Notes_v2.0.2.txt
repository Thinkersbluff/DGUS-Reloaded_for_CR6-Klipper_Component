New/Modified Features at this release:
Improved ABL Session Handling
  - Added logic to automatically clear the abl_active flag once the probe matrix is fully populated or the final probe(s) have completed.
  - This enhancement ensures the display correctly transitions from the probing matrix to the bed‑leveling page only after the ABL process is complete.
  - Includes exception handling to prevent errors if probe state data is unavailable.

Bugs/Issues Resolved at This Release:	
1. Delete File Button was not working - variable address now reconciled with DWIN_SET.
2. Total Time Elapsed display may not have been working.  Variable address now reconciled with DWIN_SET.
3. #94 - If the Filament Sensor is Triggered, subsequent prints may show the Print Paused screen instead of the Print Status screen, while printing.  Patched vars_in.cfg and added a defensive change to the cmd_DGUS_PRINT_START routine in t5uid1.py.  Both changes clear the printer_is_paused state set by M600.

Known Issues at this Release: 
- No changes since v1.3.6:
  - The displayed slicer-estimated print time remaining value may toggle between two values, if the print is performed faster than the slicer anticipated (e.g. if the feed rate is increased to a value greater than 100%)
  - The filelist, scroll and delete file scripts expect your gcode files to be stored in the default Klipper Virtual SD card directory:  ~/printer_data/gcodes. If your gcodes are stored in a different directory, they may not work for you
    - I use long filenames, so I designed the list to capture all of the .gcode files in all subfolders, but to NOT display the subfolder names in the list 
    - If you use subfolders to store different versions of files with the same name, you may not like this list.

If a future Klipper update renders your system inoperable, you can try rolling the Klipper on your system back by pinning it to this version, as follows:

SSH into your host and run these commands:

###

cd ~/klipper
sudo systemctl stop klipper
git fetch --all --tags
git checkout 2fb3d54e2f8086fb310936c9136dbb05dc753ed5
git rev-parse --short HEAD
sudo systemctl start klipper
sudo systemctl status klipper --no-pager

###

Note: “detached HEAD” is normal when pinned to a specific commit.
To return to normal tracking later: git switch master (or your usual branch) and then git pull.
