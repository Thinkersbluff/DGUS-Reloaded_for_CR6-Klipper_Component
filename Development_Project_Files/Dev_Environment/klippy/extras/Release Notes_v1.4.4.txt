New at release 1.4.4

WELCOME!

If this is your first installation of DGUS-Reloaded for CR6Community, I recommend that you:
   1. install and configure Mainsail and Klipper on your system first
   2. modify that base installation, using the following elements of the content in this repository:
      - ~klipper/klippy/extras/t5uid1 (folder and contents)
      - Related Changes (configuration files and klipper.bin file for your motherboard)
   3. install and configure the Stable_Z-Home add-in
   4. tailor your slicer configuration, per any guidance in README.MD
   5. using Mainsail, verify that your system now works correctly, except for the stock display. (Troubleshoot and resolve any issues, if/as applicable.)
   6. return to the DWIN_SET component repository, to flash the matching release of DWIN_SET and integrate the stock TFT display into your system.
   7. verify that the stock display now functions with Klipper, as described in the release notes for that version of the DWIN_SET component.

If you are here to update an existing installation of DGUS-Reloaded for CR6Community, I recommend that you:
   1. replace the contents of the ~klipper/klippy/extras/t5uid1 folder on your Klipper host, with the new version in this release
   2. use Winmerge to compare your current Klipper/Mainsail configuration files with the new configuration files of the same name in the Related Changes folder and incorporate any changes that you see at this release
   3. tailor your slicer configuration, if the Related Changes folder contains any modified instructions at this release
   4. using Mainsail, verify that your system now works correctly, except for the stock display
   5. return to the DWIN_SET component repository, to flash the new release of DWIN_SET and re-integrate the stock TFT display into your system.
   6. verify that the stock display now functions with Klipper, as described in the release notes for the new version of the DWIN_SET component.


New/Modified Features at this release:

1. Added support for the BTT Smart Filament Sensor v1.0, while retaining the stock switch sensor type as the default config.
   Moved the filament RunoutSensor configuration into its own cfg file, according to sensor type, with an [include...] in printer.cfg. 
   Made vars_out.cfg conditional, based on which type is defined in printer.cfg.
 
Bugs/Issues Resolved at This Release:	

 -  #84: The Auto_Unload_After_Print function ignores the Enable/Disable Toggle Button
 -  #83: The display switches prematurely away showing the probing screen (checkmarks) almost immediately
 -  #81: Rotation Distance is not updating with new value
 -  #80: Change Filament Temperature Preset buttons are not responsive
 -  #79: FIRMWARE_RESTART and RESTART take so long to affect the display that one wonders whether the command is running...
 -  #77: Auto Unload of filament may overspeed extruder, if Flow Rate >> 100
 -  #76: The PID menu temperature value defaults to the init_py pla constants instead of to the type1 preset values
 -  #75: Updating the displayed State of RUNOUT_SENSOR and of AUTO_UNLOAD_FILAMENT_AFTER_PRINT sometimes takes up to 2 seconds


Known Issues at this Release: 
- #82: PID may cause printer Shutdown, if thermistor is stock and [extruder] sensor_type = Honeywell 100K 135-104LAG-J01
- #78: Load_Profile button on Automatic Bed Leveling page sometimes fails to cycle through the profiles
- No changes since v1.3.6:
 - The displayed slicer-estimated print time remaining value may toggle between two values, if the print is performed faster than the slicer anticipated (e.g. if the feed rate is increased to a value greater than 100%)
 - The filelist, scroll and delete file scripts expect your gcode files to be stored in the default Klipper Virtual SD card directory:  ~/printer_data/gcodes. If your gcodes are stored in a different directory, they may not work for you
 - I use long filenames, so I designed the list to capture all of the .gcode files in all subfolders, but to NOT display the subfolder names in the list 
  - If you use subfolders to store different versions of files with the same name, you may not like this list.
