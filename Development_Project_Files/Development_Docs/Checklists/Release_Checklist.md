# Release Checklist

## Scope and Branch
- [ ] Correct branch checked out
- [ ] Branch synced with origin
- [ ] Scope matches milestone/release goal

## Versioning
- [ ] Version updated in all required files
- [ ] Date stamps updated
- [ ] Compatibility map updated

## Testing
- [ ] Core functional tests passed
- [ ] Regression tests passed
- [ ] Installation-path validation passed

## Documentation
- [ ] Installation docs updated for this release
- [ ] Release notes updated
- [ ] Cross-links and filenames verified

## Git/PR Hygiene
- [ ] `git status` clean
- [ ] No unresolved conflicts
- [ ] PR base/compare correct
- [ ] Reviewer notes included

## Release
- [ ] Tag created
- [ ] Assets uploaded/verified
- [ ] Post-release smoke check complete
