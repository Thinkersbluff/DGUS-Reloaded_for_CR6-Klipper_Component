# Development Docs

This folder is the developer operating system for this repository.

## Start here
1. `SOPs/00-Quick_Primer.md` (return-to-project refresher)
2. `Development_Manual.md` (single source of truth)
3. `SOPs/02-Release_Process.md` + `Checklists/Release_Gate_Checklist.md`

## Strict release gate
A release is blocked unless:
- all checklist gates are completed,
- all bug-fix claims are verified with evidence,
- pre-release scripts pass locally and in GitHub Actions.

## Structure
- `Development_Manual.md`
- `SOPs/`
- `Checklists/`
- `Templates/`
- `Scripts/`
- `Verification/` (per-release claim verification files)
